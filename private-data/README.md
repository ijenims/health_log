# 非公開データ保管領域

このフォルダは、本人の健康診断データをローカル開発で使用するための保管場所です。

## フォルダ構成

```text
private-data/
├─ originals/  # Googleスプレッドシートから取得した未加工の原本
├─ imports/    # Health Logへ取り込む形式へ整えたCSV
├─ exports/    # Health Logから書き出したCSV
└─ backups/    # 作業前や変換前のバックアップ
```

## 運用ルール

- 実データは`src/`や`public/`へ置かない。
- Googleスプレッドシートからダウンロードしたファイルは、まず`originals/`へ保存する。
- 原本は直接編集せず、変換したCSVを`imports/`へ保存する。
- このフォルダ内の実データはGit管理・GitHub公開の対象外。
- 画面確認時は、取込み処理を通して実データを読み込む。
- バックアップにも健康情報が含まれるため、外部共有しない。
- 本番データは月1回と大量変更前に`データ管理`からJSON書出しし、`backups/`へ保存する。
- JSONを復旧用、CSVを閲覧・確認用とする。
- AWS側の詳しい手順は`docs/backup-and-recovery.md`を参照する。

`README.md`だけは運用方法を共有する目的でGit管理できますが、その他の内容は`.gitignore`で除外されています。
